## 零、架构总览

### 0.1 升级前（当前状态）

```
用户输入 → phase_build_context → 主循环（最多 6 轮）
                                      │
                                      ├─ LLM 判断要不要调工具（26 个工具）
                                      ├─ 调了 → 结果入上下文 → 下一轮
                                      └─ 没调 → phase_finish → 回复

Scheduler → RadarPipeline._run_inner() → Screener → Vision → Cluster → Analysis → Alert
                                              ↑
                                         5 步硬编码，不可组合

Admin Monitor: 监控 Agent 工具调用 / 熔断 / 记忆 / 诊断，不监控工作流
打断机制: Agent SSE / Pipeline / Crawler 三种场景，不覆盖工作流
```

### 0.2 升级后（目标状态）

```
                          用户输入
                             │
                             ▼
    ┌─────────────────────────────────────────┐

    │  → ③ LLM规划(含criticality标注)         │
    │  → ④ 动态调整(异常时触发)                │

```
