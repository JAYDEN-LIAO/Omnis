## 一、集成测试用例

### 1.1 原子工具独立调用

```bash
# 1. 采集测试
curl -X POST /api/agent/chat \
  -H "Authorization: Bearer $TOKEN" \
  -d '{"messages": [{"role": "user", "content": "搜索小红书关于长沙旅游的帖子"}]}'

# 预期：Agent 调用 search_posts(keyword="长沙旅游", platforms=["xhs"])
# 验证：返回的帖子数量 >= 5，每条含 title/content/platform/url
```

```bash
# 2. 过滤测试
# Agent 调用 filter_content(posts, intent="guide")
# 验证：过滤后仅保留攻略/体验类内容，广告被排除
```

```bash
# 3. 情感分析测试
# Agent 调用 analyze_sentiment(texts)
# 验证：规则判定覆盖 ≥ 80%，LLM 仅在模糊内容时调用
```

# 工作流取消（v2.0）

目标：用户可取消自己正在执行的定时工作流；Admin 可取消任意用户工作流。

触发链路：
  POST /api/agent/workflows/{wf_id}/cancel  →  cancel_registry.cancel_workflow(wf_id)
                                              ↓
  scheduler._WF_CANCEL_EVENTS[wf_id].set()  →  execute_workflow_steps 检测到后返回 cancelled

详见 upgrade2.0/05-P4-用户工作流与调度.md 第五节
