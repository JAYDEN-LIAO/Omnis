# P6 — 管线退化适配（调度器切换）

> 依赖：P1（组合工具层）
> 目标：调度器的定时扫描入口从直接实例化 RadarPipeline 改为走组合工具
> 原则：旧路径保留作为回退，渐进式切换

## 一、问题与方案

```
旧路径: Scheduler → RadarPipeline._run_inner() → 5 步硬编码
新路径: Scheduler → 触发组合工具 scan_and_alert → search_posts → filter_content → cluster → analyze_sentiment → push
```

组合工具被 `@with_owner` 装饰，必须在调用前 `set_current_owner(oid)`，否则 `with_owner` 装饰器会抛 `OwnerRequiredError`。

## 二、实现（★ R-015 修订版：set_current_owner 跨线程显式注入）

```python
# backend/services/radar_service/scheduler.py
# 修改 _run_extra_pipelines 函数

import os

USE_COMPOSITE_TOOLS = os.getenv("USE_COMPOSITE_TOOLS", "0") == "1"


def _run_extra_pipelines(owner_id: str, pipeline_types: list[str], keywords: list[str]):
    """为非风险 pipeline 类型运行轻量级分析（复用已爬取数据）。

    ★ R-015 修订：根据 USE_COMPOSITE_TOOLS 开关走新/旧路径；
                  新路径必须显式 set_current_owner（ContextVar 不跨线程）。
    """
    if USE_COMPOSITE_TOOLS:
        return _run_extra_pipelines_composite(owner_id, pipeline_types, keywords)
    return _run_extra_pipelines_legacy(owner_id, pipeline_types, keywords)


def _run_extra_pipelines_legacy(owner_id: str, pipeline_types, keywords):
    """旧路径：直接实例化 RadarPipeline（保留作为回退）"""
    from .pipeline_configs import PIPELINE_BUILDERS
    from .pipeline import PipelineConfig, RadarPipeline

    for pt in pipeline_types:
        builder = PIPELINE_BUILDERS.get(pt)
        if not builder:
            logger.warning(f"[Scheduler] 未知 pipeline_type={pt}，跳过")
            continue

        try:
            from .db import get_unprocessed_posts
            from backend.core.config import settings

            pipeline = builder(keywords[0] if keywords else "", [], owner_id)
            platform = pipeline.config.platform

            posts = get_unprocessed_posts(settings.CRAWLER_DB_PATH, platform)
            if posts:
                loop = asyncio.get_running_loop()
                results = loop.run_until_complete(pipeline.run(posts))
                logger.info(
                    f"[Scheduler] {pt} pipeline 完成: {len(results)} 条结果"
                    f" (user={owner_id[:8]}...)"
                )
            else:
                logger.info(f"[Scheduler] {pt} pipeline: 无未处理数据")
        except Exception as e:
            logger.error(f"[Scheduler] {pt} pipeline 异常: {e}", exc_info=True)


def _run_extra_pipelines_composite(owner_id: str, pipeline_types, keywords):
    """新路径：走组合工具（★ R-015 关键：set_current_owner 跨线程）"""
    from backend.services.agent_service.tools._owner import (
        set_current_owner, reset_current_owner,
    )

    loop = asyncio.get_running_loop()
    # ★ R-015 关键：scheduler 线程是新 loop，ContextVar 必须显式 set
    token = set_current_owner(owner_id)
    try:
        # ★ R-015 同样需要 set cancel_event（cron 触发时不感知取消，但显式 None）
        from backend.services.agent_service.tools._base import (
            set_current_cancel_event, get_current_cancel_event,
        )
        cancel_token = set_current_cancel_event(None)

        # 在子函数中 import（避免循环导入 + 锁住模块加载顺序）
        from backend.services.agent_service.tools.composite import (
            deep_analyze_topic, scan_and_alert, briefing_digest,
        )

        try:
            for pt in pipeline_types:
                if pt == "risk":
                    continue  # risk 走原 job_async
                kw = keywords[0] if keywords else ""
                plat = ["wb", "xhs"]  # 默认平台（可扩展：读 subscription.platforms）

                if pt == "guide":
                    result = loop.run_until_complete(
                        deep_analyze_topic(
                            keyword=kw, analysis_type="guide",
                            platforms=plat, _owner_id=owner_id,
                        )
                    )
                elif pt == "celebrity":
                    result = loop.run_until_complete(
                        deep_analyze_topic(
                            keyword=kw, analysis_type="celebrity",
                            platforms=plat, _owner_id=owner_id,
                        )
                    )
                elif pt == "briefing":
                    result = loop.run_until_complete(
                        briefing_digest(
                            keyword=kw, platforms=plat, _owner_id=owner_id,
                        )
                    )
                elif pt == "alert":
                    result = loop.run_until_complete(
                        scan_and_alert(
                            keyword=kw, platforms=plat,
                            channel="email", _owner_id=owner_id,
                        )
                    )
                else:
                    logger.warning(f"[Scheduler] 未知 pipeline_type={pt}")
                    continue

                logger.info(f"[Scheduler] {pt} composite 完成 (user={owner_id[:8]})")
        finally:
            set_current_cancel_event(None)  # 重置（虽然已经清空，但要语义一致）
    finally:
        reset_current_owner(token)
```

## 四、验收标准

- [ ] `USE_COMPOSITE_TOOLS=0` 时调度器走旧路径，行为与升级前完全一致
- [ ] `USE_COMPOSITE_TOOLS=1` 时调度器走组合工具
- [ ] **R-015**：scheduler 入口 `set_current_owner(oid)` 必须在线程入口调用（ContextVar 不跨线程）
- [ ] **R-015**：reset_current_owner(token) 必须配对调用（否则 ContextVar 泄漏）
- [ ] risk / guide / celebrity / briefing 四条线都能正常执行
- [ ] 新旧路径的输出结果结构和内容一致（抽样对比 5 次运行）
- [ ] 切换路径后 24h 内无未处理告警积压
